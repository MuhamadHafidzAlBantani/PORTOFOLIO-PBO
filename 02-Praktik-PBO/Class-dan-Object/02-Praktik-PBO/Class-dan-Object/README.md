
# Program Penonton Konser

## Deskripsi
Program ini merupakan simulasi percakapan antara dua orang penonton konser menggunakan konsep Pemrograman Berorientasi Objek (PBO) dengan bahasa Python.

## Konsep PBO yang Digunakan

1. Class: PenontonKonser
2. Object: orang1 dan orang2
3. Attribute: nama, kota, dan band
4. Method:
   - perkenalan()
   - menyapa()
   - asal_kota()
   - membahas_band()

## Tujuan Program
Memahami penerapan class, object, attribute, dan method dalam Python.

## Bahasa Pemrograman
Python
